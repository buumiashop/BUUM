# BUUM Knowledge Base (BKB)

El hogar permanente y **único** de todo el conocimiento definitivo de BUUM. A partir de su creación, la empresa depende de estos documentos oficiales y **nunca más del historial de un chat**.

## Reglas de la Knowledge Base

1. **Fuente única de verdad.** Un conocimiento vive en exactamente un documento. Si hay dos versiones, una está mal.
2. **Cada documento tiene dueño, versión y función.** El registro autoritativo de estos tres datos es [`REGISTRO-DE-DOCUMENTOS.md`](REGISTRO-DE-DOCUMENTOS.md).
3. **Solo conocimiento definitivo.** Aquí no entran chats, borradores ni experimentos. Entra lo que es verdad estable para la empresa.
4. **Regla de graduación.** El conocimiento en construcción o en validación vive en su espacio de trabajo (el repo del BIS) hasta que se ratifica; entonces **gradúa** a esta base. No se migra lo que aún no es definitivo.
5. **Nada se borra.** El conocimiento superado se retira a [`99-archivo/`](99-archivo/), no desaparece.

## Cómo usar la KB

- **Para saber qué es verdad en BUUM:** se busca aquí, nunca en un chat.
- **Para saber quién manda sobre un documento y qué versión rige:** [`REGISTRO-DE-DOCUMENTOS.md`](REGISTRO-DE-DOCUMENTOS.md).
- **Para entender qué se trajo del proyecto anterior y qué se dejó fuera:** [`MIGRACION.md`](MIGRACION.md).
