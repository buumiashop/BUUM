# ADR-0017 — Información obligatoria para la Auditoría (Paso 2)
- **Fecha:** 2026-07-17 · **Estado:** Aceptada
- **Contexto:** La Auditoría necesita saber qué info es obligatoria para decidir si avanza o pide más.

## Decisión (B2)
Lista mínima **por producto**, que evoluciona con cada nuevo producto (no taxonomía universal prematura).

### Reflector solar LED — obligatorios / recomendables / opcionales
- **Obligatorios:** nombre/modelo · potencia (W) · alimentación (panel + batería) · lúmenes · color de luz · IP · dimensiones · contenido del empaque · garantía · certificación (o "no aplica") · fotos.
- **Recomendables:** sensor/control · autonomía · tiempo de carga · peso.
- **Opcionales:** código de barras · compatibilidades.
- **Regla:** si falta un **obligatorio** → se solicita antes de avanzar.

## Alternativas
- B1 Taxonomía universal ahora (prematura, viola "evidencia no hipótesis").

## Consecuencias
- La lista crece producto a producto (evolución con evidencia).
